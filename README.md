# Трекер задач

Full-stack Todo-приложение на FastAPI + PostgreSQL + Nginx, полностью контейнеризированное через Docker Compose. Nginx собран из исходников для демонстрации multi-stage build и конфигурирования через envsubst.

## Stack

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.0
- **Frontend:** Nginx (собран из исходников), vanilla JS
- **Database:** PostgreSQL 16
- **Инфраструктура:** Docker, Docker Compose

### Быстрый старт

```bash
git clone https://github.com/Tygosilver/TygoTodoFullApp.git
cd TygoTodoFullApp
cp .env.example .env       # при необходимости поправь значения
docker compose up -d --build
```
